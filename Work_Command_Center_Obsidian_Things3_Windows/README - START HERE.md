# Work Command Center — Obsidian Things Edition for Windows

This is the **work version** of the organizational system.

## Purpose
Use this vault to stay prepared, track commitments, follow up reliably, manage projects and meetings, record decisions and risks, and retrieve work information quickly.

## Windows setup
1. Unzip this package into a folder you are permitted to use.
2. Open Obsidian → **Open folder as vault** → select `Work_Command_Center_Obsidian_Things3_Windows`.
3. Settings → Appearance → Themes → install/select **Things**.
4. Settings → Appearance → CSS snippets → enable `work-command-center-things`.
5. Settings → Community plugins → install and enable **Dataview**.
6. Use the command **Open today's daily note**.

No administrator rights are normally required for the vault itself; plugin/theme availability can still depend on your organization's security policy.

## Daily behavior
Daily Notes is already configured:
- folder: `01 - Daily`
- filename: `YYYY-MM-DD`
- template: `Daily Work Command Center`

The first time you open today's Daily Note, Obsidian creates it. Later openings return to the same page.

## Automatic Command Center roll-ups
Dataview reads structured Properties from:
- Projects
- Follow-Ups
- Risks & Issues
- Meetings
- Documents
- open tasks

Update the source note once; the live dashboard reflects the current state.

## Main templates
- Daily Work Command Center
- Work Project
- Meeting Note
- Work Follow-Up
- Decision Record
- Risk or Issue
- Work Document Review
- Team 1-on-1
- Weekly Work Review
- Work Someday & Ideas

## Someday & Ideas
`11 - Someday & Ideas` is intentionally isolated. It does **not** feed the Daily Command Center. Use it for future initiatives, automation ideas, improvements, learning, or possibilities that are not commitments.

## Visual design

Accent: #007AFF

Cards: light gray
Text: graphite
Writing rows: persistent CSS bottom borders

## Operating principle
**Capture once. Store in the right source note. Let the Command Center surface what requires attention.**
