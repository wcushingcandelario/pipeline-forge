# Windows Work Command Center — Obsidian v2

This is a separate Windows work vault modeled after the fuller Mac Personal Command Center design.

## What is included
- Work Command Center dashboard
- Morning Work Reset
- Today's Top 3
- Work Inbox
- Waiting / Follow-Up
- Projects
- Meetings & Prep
- Documents & Reviews
- Risks & Blockers
- Decisions
- Team / 1-on-1s
- Quick Capture
- End-of-Day Reset
- Weekly Review
- Reusable work templates
- Things-inspired light blue CSS snippet

## Open it in Obsidian on Windows
1. Extract the ZIP.
2. Open Obsidian.
3. Choose **Open folder as vault**.
4. Select the extracted `Windows_Work_Command_Center_Obsidian_v2` folder.
5. Open `01 - Daily/Work Command Center.md`.

The CSS snippet is already included and enabled in `.obsidian/snippets`.

## Recommended first setup
- Pin `Work Command Center`.
- Add `Weekly Review` to bookmarks.
- Create a note for each active project from `90 - Templates/Project Template`.
- Create one ongoing note per direct report from `90 - Templates/1-on-1 Template`.
- Keep all quick capture in `00 - Inbox/Work Inbox`.

## Optional plugins
The vault works without community plugins.
If you already use Dataview or Tasks, they can be added later for automatic roll-ups.
