# Work Command Center — How To Use

## Core Loop
**Capture → Organize → Execute → Review**

## Daily
1. Open [[01 - Daily/Work Command Center]].
2. Run Morning Work Reset.
3. Set Today's Top 3.
4. Capture actions, decisions, risks, waiting items, and documents as work happens.
5. Run End-of-Day Reset.

## Weekly
Run [[01 - Daily/Weekly Review]].

## Operating Rules
- Capture once.
- Decide where it belongs.
- Do not let actionable work live only inside meeting notes.
- Every project should have a clear next action.
- Every waiting item should have a follow-up date.
- Every material decision should have context and rationale.
- Review routinely instead of relying on memory.
